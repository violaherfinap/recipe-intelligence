## 7. Sequence dan Paralel

Critical path:

```text
Lois base/integration
  -> Anin dev query + gold + pool
  -> Dhea/Vio label blind
  -> Lois adjudikasi + freeze dev
  -> Lois tau + Anin NLI
  -> config freeze
  -> Vio B4/B5 test + A3/A6
  -> Gate 3
```

Bisa paralel:

- Awal: Lois menyiapkan base; Anin draft query; Dhea menyiapkan dataset/training; Vio menyiapkan harness A3/A6.
- Setelah query dev ada: Dhea dan Vio label blind bersamaan.
- Setelah dev freeze: Lois tau; Anin NLI; Dhea training; Vio persiapan.
- Setelah config freeze: Lois B4 dev; Anin B4 report; Dhea B5 dev/OOD; Vio B4 test + A3/A6.
- Setelah adapter tersedia: Vio A4 + B5 test.
- Setelah test: Vio 3 seed; Gate 3.

Tidak boleh paralel atau didahulukan:

- Label sebelum query.
- Kalibrasi sebelum dev frozen.
- Test sebelum config freeze.
- A4/B5 sebelum adapter.
- Tuning threshold setelah test dimulai.
